# Online Survey Application

**Developed by: Deepika S**

## About the Project
The Online Survey Application allows users to submit feedback through an online form. Submitted feedback is stored in MongoDB.

## Technologies Used
- React.js
- Node.js
- Express.js
- MongoDB
- CSS
